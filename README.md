# Online Bank Application Form

Fill in the Nissan bank application in the browser, sign it on screen, and print or save it as a PDF.

**Live page:** https://kevinsornet.github.io/Online-Bank-Application-form/

## How to use
1. Pick the dealer branch at the top of the form.
2. Fill in the fields. The preview on the right shows exactly what will print.
3. Sign in the E-signatures pads.
4. Click **Print / Save PDF** and choose "Save as PDF" (paper size: Legal).

Everything you type stays in your own browser. Nothing is sent to a server. Click **Clear** before starting the next client.
